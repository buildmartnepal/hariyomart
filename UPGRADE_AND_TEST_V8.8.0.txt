HARIYO MART NEPAL v8.8.0 — UPGRADE & TEST
==========================================

CLOUDFLARE WORKERS BUILDS
Build command:
  npx @opennextjs/cloudflare build

Recommended deploy command:
  npm run deploy:cloudflare:production

The production deploy command keeps the standalone public Worker topology, applies remote D1 migrations, refreshes the idempotent marketplace/test seed when Production Test Mode is enabled, validates configuration and deploys OpenNext.

12. Admin — products, reviews, matching engine, orders, inventory, analytics and audit.
13. Mobile/native — verified/same-day filters, product minimum-order step and delivery/seller trust.

REAL PRODUCTION CUTOVER
1. Configure JWT_SECRET, JWT_REFRESH_SECRET and TURNSTILE_SECRET_KEY as Cloudflare Worker secrets.
2. Keep the public Turnstile site key in the Dashboard (keep_vars=true preserves it).
3. Set NEXT_PUBLIC_DEMO_MODE=false and PRODUCTION_TEST_MODE=false.
4. Run npm run production:demo:remove.
5. Redeploy.
6. Verify /api/system/readiness reports ready.
