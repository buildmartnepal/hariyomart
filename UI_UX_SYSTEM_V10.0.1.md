# Hariyo Mart Nepal v10.0.1 — UI/UX & Brand System

## Named palette
- Hariyo Forest `#063B2B` — primary brand depth, headings and dark surfaces.
- Nepal Leaf `#168A55` — primary action and success.
- Fresh Lime `#98E342` — freshness/highlight/accent.
- Marigold Gold `#F4B942` — review/pending/trade attention.
- Rhododendron `#D94F70` — important alert/error emphasis.
- Himalayan Sky `#3C8DBC` — information/export logistics.
- Earth `#A7643B` — producer/origin cues.
- Snow Mist `#F7FAF4` — light surface.
- Warm Cream `#F5F0E7` — editorial/origin surface.
- Night Pine `#041F18` — dark-mode foundation.

## Principles
- Auto Day/Auto Night use the same semantic tokens rather than separate page-specific palettes.
- Product cards prioritize photo → name → seller/origin → price/stock → fulfillment → action.
- Export/trade states use semantic Ready / Review / Alert / Information tokens.
- Minimum interactive target is touch-friendly; mobile search, cart and buy actions remain reachable with one hand.
- Safe-area padding is retained for mobile commerce navigation and sticky purchase controls.
- Public content uses strong storytelling, short readable sections, visual diagrams, facts, FAQs and contextual CTAs.

## Cross-platform
The native Expo app keeps five primary tabs (Home, Nearby, Shop, Cart, Account) and uses matching emerald/lime/forest semantic colors so web and mobile feel like one system.
