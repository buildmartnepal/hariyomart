# Hariyo Mart v8.9.1 — Website + Mobile UI/UX System

## Brand foundation

- Primary identity: deep Hariyo forest + emerald green.
- Energy/accent: lime for positive actions, cart badges and fresh-market highlights.
- Day surfaces: warm off-white / botanical light background, white raised cards.
- Night surfaces: deep forest background, dark green raised cards, mint action color.
- Auto mode follows operating-system light/dark preference; manual Light and Dark remain available on web.

## Interaction rules

- Minimum core controls target approximately 42–50px touch height.
- Every keyboard-focusable web control receives a visible focus ring.
- Hover elevation only runs on fine pointer devices.
- Motion is suppressed when the operating system requests reduced motion.
- Mobile fixed navigation and purchase bars respect safe-area insets.
- Search becomes a full-height sheet on small screens.

## Commerce hierarchy

1. Product image / freshness / origin.
2. Product name and seller trust.
3. Location and fulfilment context.
4. Price / savings.
5. Stock and minimum order.
6. Add-to-basket action.

## Mobile information architecture

Primary tabs: Home → Nearby → Shop → Cart → Account.

Seller entry remains prominent on Home and seller/account paths without crowding the buyer navigation.

## Cross-platform consistency

The web and Expo app share the same conceptual palette, product decision order, seller/location language and checkout terminology. Platform-native controls are retained where they improve usability rather than forcing identical visual implementations.
