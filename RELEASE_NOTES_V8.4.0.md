# Hariyo Mart Nepal v8.4.0 — Production Access & Role SaaS

This release upgrades the deployed Cloudflare-native marketplace into a stronger role-based production SaaS while preserving the v8.3.3 standalone Worker deployment topology.

## Highlights

- Real admin user/access management.
- Admin/farmer/vendor/customer identity creation.
- One-time temporary passwords, mandatory first password change and session-revoking resets.
- Account suspension and last-login visibility.
- New D1 access-control migration.
- Scrollable, single-line admin/farmer/account menu.
- Dark/light workspace contrast hardening.
- Security Center, System Health and Mobile Apps admin modules.
- Role-aware Expo mobile command center.
- Interactive production user provisioning helper.

The default web Worker remains independent of the optional `hariyo-mart-services` Worker.
