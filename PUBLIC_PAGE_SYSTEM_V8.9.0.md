# Hariyo Mart v8.9.0 — Public Page & Content System

## About

The About experience now explains not only what Hariyo Mart is, but how the marketplace model works. It includes:

- origin-first marketplace story;
- 7-province / catalogue / workspace facts;
- farmer-first, location-first and trust-record pillars;
- connected system graphic for seller, location, stock, route, order and payout;
- FAQs explaining multi-seller commerce, location matching and target user groups;
- links into Shop and How It Works.

## Contact & Support

The Contact experience now includes:

- support routing for buyer, seller, logistics and business enquiries;
- trackable D1 support-ticket workflow;
- help-type selector;
- optional order/ticket/seller reference;
- priority selector;
- improved autofill-friendly name/email/phone fields;
- stronger subject/message prompts;
- visible security notice explaining what must never be shared;
- success state with retained ticket reference;
- related Track Order and Delivery links.

## How It Works

The operating story now covers eight connected stages:

1. Seller workspace creation.
2. Seller identity and service-area verification.
3. Harvest/product/stock publishing.
4. Location-aware Hariyo Match discovery.
5. Save/compare/multi-seller basket decisions.
6. Checkout and delivery confirmation.
7. Seller-level fulfilment/tracking.
8. Reviews, support, settlement and payout.

It also contains dedicated buyer and seller journeys, a trust-checkpoint matrix, FAQs and role CTAs.

## CMS compatibility

The existing `/content/pages/:slug` CMS fetch remains intact. Published admin page sections can override the built-in editorial sections without removing the surrounding visual/FAQ/CTA experience.
