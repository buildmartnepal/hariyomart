# Hariyo Mart Nepal v6.2.0

This release turns the marketplace into a more complete web, mobile and operations product.

## Highlights

- 98 synchronized products across 23 categories and all seven provinces
- Premium square-card storefront, real system/light/dark theme and new location-first hero graphic
- Expanded home page, buyer/farmer/admin journeys, FAQs and tailored information pages
- D1-backed category and CMS page management plus R2 media index and actor-aware audit history
- Secure first-admin bootstrap for `greenmandux@gmail.com`; no password is committed
- Expo home and shop redesign with category rails, square grids and automatic light/dark appearance
- Cloudflare production guide covering D1, R2, KV, Queues, Durable Objects, security and recovery

Online payments remain disabled until merchant onboarding, webhook validation and reconciliation are
completed. Cash on delivery remains the supported release payment method.
