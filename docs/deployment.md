# Deployment

Hariyo Mart v6 deploys to Cloudflare Workers, D1, Durable Objects, R2, KV and Queues. Follow the complete provisioning, secret, migration, verification, GitHub Actions, domain and rollback instructions in [CLOUDFLARE_PRODUCTION_V6.md](CLOUDFLARE_PRODUCTION_V6.md).

The old Vercel/MongoDB/Redis/Cloudinary deployment path remains only as legacy reference in the v5 documents and is not the v6 production architecture.
