Recommended Cloudflare settings for this release:
Build command: npx @opennextjs/cloudflare build
Deploy command: npm run deploy:cloudflare:production

The production deploy command applies migrations, operational seed and test identities before publishing the Worker.

Before real production:
1. Configure JWT_SECRET and JWT_REFRESH_SECRET as Wrangler/Cloudflare secrets.
2. Configure the real Turnstile public and private keys.
3. Run: npm run demo:remove:remote
4. Set NEXT_PUBLIC_DEMO_MODE=false and PRODUCTION_TEST_MODE=false.
5. Rebuild and redeploy.
